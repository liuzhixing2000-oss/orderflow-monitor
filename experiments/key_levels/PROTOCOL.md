Primary combined policy: intersect the already formed baseline events with the position condition, preserving the baseline cooldown. This measures selection at the same original entry times, not a new timing strategy.

Positions are defined using observed minute prices (not exchange candle extrema): (1) previous UTC calendar day's minimum; (2) prior 1h minimum ending 15min before entry; (3) prior 4h minimum ending 15min before entry. Excluding the reaction window prevents the current touch from manufacturing its own historical level. Reject incomplete windows.

This is an observed-price ATR proxy, not exchange OHLC ATR. It cannot prove exact executable touches. A support reaction requires the last 15min minimum within +/-0.25 ATR of a pre-existing level, current price between level and level+0.5 ATR, and positive stored 5min price return. Reject reaction windows with insufficient coverage or stale current feeds. Both labels and scale use only data at or before entry. No parameters are varied after seeing outcomes.
